# WooCommerce-Whatsapp-Notifications-Plugin
 WooCommerce WhatsApp Notifications Plugin
 
 Features:
 
 - Notify sellers about new orders placed.
 - Update buyers on their order status and any changes made.
 - Support for all WooCommerce order statuses.
 - Customizable WhatsApp content for different order stages.
 - Integration with a variety of third-party plugins for an enriched experience.
 - Customizable Message Tags: [shop_name], [order_id], [order_amount], [order_status], [order_product], [payment_method], [bank_details], [billing_first_name], [billing_last_name], [billing_phone], [billing_email], [billing_company], [billing_address], [billing_country], [billing_city], [billing_state], [billing_postcode].

Installation:
 - Download the "MsgBucket_WordPress.zip" file from the downloads tab
 - Do not unzip the downloaded .zip file
 - Log in to your WordPress admin panel.
 - Select the plugins, then Add new.
 - Browse your computer to select the “MsgBucket_WordPress.zip” file download.
 - Click Install Now and WordPress will do its magic and install the Plugin.
 - After the installation is complete, activate the plug-in.

Settings:
 - Go to settings tab and select "MsgBucket Wordpress"
 - Select Whatsapp Gateway option and select "Custom Whatsapp Gateway"
 - Go to Api Settings and enter the Api Token from your msgbucket.com account.

Test Gateway Setting:
 - Go to Send Message tab
 - To: Specific Phone Number
 - Recepients: Your receiver phone number
 - Message: Your defined message.
 - Click Send Message
 - Go to Usage Logs tab, you will see Response from gateway: {"success":true,"message":{"csent":,"msgtext":""}}
